Fixed AnimeTimm preprocessing. Images are now scaled to fit and padded with white like the reference implementation, so large or non-square images are no longer squashed.

Fixed Pixai Tagger v0.9 in the default GPU preprocessing mode, which read the wrong model output. Its preprocessing now matches the reference: a plain resize to 448x448 instead of letterboxing on grey.

Pixai Tagger v1.0 artist tags are now reported in character_tags instead of general_tags.

WD taggers now pad to a square before resizing, matching the reference implementation.

Fixed exclude_tags adding extra backslashes to tags with parentheses. Exclusions now also match regardless of underscores or spaces.

The Hugging Face token is no longer sent when HF_ENDPOINT points to a mirror.
