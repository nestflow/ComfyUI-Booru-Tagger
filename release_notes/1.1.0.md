- Added **Pixai Tagger v1.0** (FP16 and FP32): 30,877 tags at 1008², with its recommended per-category thresholds.
- **Faster tagging on CUDA/ROCm**: images are now preprocessed on the GPU and fed to the model directly, skipping the CPU preprocessing and host round-trip.
- Moved `replace_underscore` to the Booru Tagger node; toggling it no longer reloads the model.
- Threshold inputs left unconnected now use each model's recommended values instead of the global defaults.
- New `chunk_size` option to limit how many images go through the model in one call.
